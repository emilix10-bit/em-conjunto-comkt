# Manual de Convocação de Remanescentes - Agentes de Contratação

Este repositório contém a documentação em MkDocs para o manual de convocação de remanescentes no Compras.gov.br direcionado aos **Agentes de Contratação**.

## Estrutura do Repositório

No ramo principal, deve ser criada a pasta `docs`.

Nessa pasta, criar as pastas:
- `Imagens`: onde são colocadas todas as imagens. (Atenção para a letra maiúscula no nome da pasta e use apenas arquivos com nomes sem espaço e sem caracteres especiais, incluindo ç e acentos).
- `css`: onde consta o arquivo `extra.css`.
- `js`: onde constam os arquivos `custom.js` e `font-size.js`.

Na pasta `docs` também constam:
- Os arquivos com as seções do manual em extensão `.md`
- O arquivo `custom.css`
- O arquivo `index.md` com a página inicial e os links para cada uma das seções
- O arquivo `manual-completo.md`, que compila todas as seções
